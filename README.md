# Omarchy Pilot

Aviation weather for the [Omarchy](https://omarchy.org/) status bar. One
aerodrome, its METAR, its TAF, and a flight-category label.

Status: **in development.** Not yet usable.

## Install

```bash
omarchy plugin add https://github.com/mittsh/omarchy-pilot.git --enable
omarchy bar set pilot.metar icao EETN
```
